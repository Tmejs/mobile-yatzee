# Mobile Yatzee

Mobile Yatzee is a planned Flutter and Spring Boot dice game for iOS and Android. The approved conversational direction covers solo score challenges, local pass-and-play, versioned Generał/Yahtzee/Yatzy rulesets, localization, offline play, Apple/Google-linked ranked profiles, weekly country/continent/global rankings, and a staged ads-plus-lifetime-Premium business model.

Implementation has not started. The current repository checkpoint contains planning and workflow documentation only.
