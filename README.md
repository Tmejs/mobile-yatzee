# Mobile Yatzee

Mobile Yatzee is a planned Flutter and Spring Boot dice game for iOS and Android. The approved conversational direction covers solo score challenges, local pass-and-play, versioned Generał/Yahtzee/Yatzy rulesets, localization, offline play, and weekly country, continent, and global rankings.

Implementation has not started. The current repository checkpoint contains planning and workflow documentation only.
